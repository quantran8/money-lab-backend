# Event System

Events represent meaningful life choices.

Recommended frequency:


0–4 events per month


---

# Event Structure

Event template:


LIFE_EVENT_TEMPLATES


Options:


LIFE_EVENT_OPTIONS


Each option defines:


money_delta
health_delta
lqi_delta
learning_xp_delta
default_jar_code


---

# Payment Logic

Players can pay from any jar.

If insufficient:


primary jar

cover jars


must fully cover cost.

Payment breakdown is stored as JSON.
